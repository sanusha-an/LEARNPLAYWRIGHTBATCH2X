# LEARNPLAYWRIGHTBATCH2X

A learning repository for Playwright automation testing with JavaScript. This project covers fundamental concepts of JavaScript needed for Playwright test automation.

## Contents

- **Chapter 1: Basics** - JavaScript basics and Playwright commands
- **Chapter 2: JavaScript Concepts** - Variables, identifiers, and comments
- **Chapter 3: Identifiers & Literals** - (Coming soon)

## Prerequisites

- Node.js
- Playwright

## Getting Started

```bash
npm install
npx playwright install
```
